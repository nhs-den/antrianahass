Ulasan Google

        
Kotak ke-3. Pilih sumber data ulasan.


        

          

          

            

              Bawaan (tanpa aplikasi tambahan): panel sudah menjalankan widget ulasan sendiri di
              port 3000 dan menyala otomatis setiap boot. Cukup isi URL JSON ulasan
              di bawah, atau isi API key + Place ID di menu Google Places.
            

            
            

              Sudah punya aplikasi ulasan-google terpisah? Tempel kode embed-nya di bawah
              (atau isi kolom Host). Bila kode embed / host diisi, panel memakai aplikasi itu,
              bukan widget bawaan.
            

            
            

              
              
              
            

            
            

              
            

          


          

            
Layanan ulasan (port 3000)

            

              Widget ulasan menyala otomatis bersama panel: bila ada aplikasi
              ulasan-google terpisah, panel menjalankannya; bila tidak ada, panel memakai
              widget bawaan (loader.js + /reviews.json di port yang sama) sehingga tidak
              perlu memasang apa pun lagi. Status dan tombol di bawah bekerja langsung di perangkat ini.
            


            

              
              memeriksa…
              
            


            

            

            

            

              
              
              
              
            

            

              Agar tetap hidup setelah perangkat reboot, pasang autostart sekali
              (butuh panel berjalan sebagai root) — atau jalankan
              sudo bash /opt/antrianahass/deploy/install-ulasan.sh.
            

          



          

            
Cara mendapatkan kode ulasan Google

            

              Aplikasi ini menampilkan widget dari proyek
              ulasan-google (bukan langsung dari Google), karena API resmi Google
              hanya memberi ulasan lewat Places API yang berbayar.
            


            
    
              
  1. 
                Jalankan service ulasan di perangkat yang menyala terus (boleh PC yang sama
                dengan panel). Repo: nhs-den/ulasan-google.
                
    npm install
npm start          # default port 3000
    
              
    2. 
              
  2. 
                Uji di browser: buka http://IP-SERVICE:3000/.
                Kalau widget ulasan tampil, service siap dipakai.
              
    3. 
              
  3. 
                Ambil kode embed dari service itu (biasanya di halaman
                /embed atau tombol “Embed”). Bentuknya seperti ini:
                
    <script>(function(){var p=document.currentScript.parentNode;
  /* … memuat loader.js?kiosk=1 … */}());</script>
    
                Tempel apa adanya di kolom “Kode embed” di atas.
              
    4. 
              
  4. 
                Isi manual (tanpa kode embed) — cukup tiga kolom di atas:
                Port 3000, Path /loader.js, Query kiosk=1,
                dan Host = IP komputer tempat service berjalan
                (biarkan kosong bila service ada di perangkat yang sama dengan panel).
              
    5. 
              
  5. 
                Tekan Simpan, lalu Buka pratinjau widget untuk memastikan tampilannya.
              
    6. 
            


            

              Kalau service berjalan di PC lain, jangan lupa buka port 3000 di firewall PC itu.
              Uji dari perangkat ini:
              curl -s http://IP-PC:3000/loader.js?kiosk=1 | head -3
